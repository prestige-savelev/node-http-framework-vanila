# Mini Express — Lightweight Node.js Framework

A lightweight web framework built from scratch using vanilla Node.js, inspired by Express.js.

The project explores the fundamentals of HTTP servers, request handling, routing, middleware architecture, and response management without relying on external frameworks.

### Features
- Custom HTTP server built with Node.js
- Route handling for different HTTP methods
- Request and response processing
- Middleware support
- Modular architecture
- Error handling

### Tech Stack
- Node.js
- JavaScript
- Native HTTP module

### Goal
To understand how web frameworks like Express.js work internally by implementing their core functionality from scratch.
